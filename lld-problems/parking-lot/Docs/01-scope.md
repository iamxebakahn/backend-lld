# Parking Lot Management System
**Design a Parking Lot Management System.**
The system should allow vehicles to enter a parking lot, receive a ticket, park in an allocated spot,
pay the parking fee at exit, and leave the parking lot.

## System Type
**This is a Parking Lot Management System.**
The objective is to manage:

- Parking Floors
- Parking Spots
- Vehicles
- Gates
- Tickets
- Bills
- Payments

## Data Storage
For this assignment:

- Data will be stored in memory.
- No actual database will be used.
- Repository layer will simulate storage.

## Input Assumption
Parking lot data will be hardcoded.

Examples:

- Floors
- Gates
- Spots
- Vehicle Types
will be created manually in code.

## In Scope
- Multiple Floors
- Multiple Parking Spots
- Entry Gates
- Exit Gates
- Ticket Generation
- Spot Allocation
- Bill Generation
- Payment Handling
- Refund Handling

## Out Of Scope
- CCTV Integration
- Number Plate Recognition
- Mobile Application
- Analytics Dashboard
- Parking Reservation
- Real Payment Gateway Integration
